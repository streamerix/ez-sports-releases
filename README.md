# EZ Sports — Android TV app

Download the latest version: **https://ezgameday.streamerix.tv/app**
(or [latest release](https://github.com/streamerix/ez-sports-releases/releases/latest))

## Install on Android TV / Fire TV
1. Install the **Downloader** app from your TV's app store.
2. Open Downloader and enter the link above (or your Downloader code).
3. If Android asks, allow Downloader to install apps.
4. Tap **Install**, then open **EZ Sports** and sign in with your username and password.

Updating: download and install again — your favourites, Live Tracker and PIN are kept.
